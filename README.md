# Expense Tracker GUI

📌About the Project
Expense Tracker GUI is a Python-based desktop application designed to help users track and manage their personal expenses through a graphical user interface.

This project was created to practice Python programming and GUI application development.

# Features

- Graphical User Interface (GUI)
- Expense tracking
- Simple and user-friendly interface
- Desktop application
- Python-based functionality

- Tkinter (if used in this project)

# How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Run the following command:

python expense_tracker.py
